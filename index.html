Self-balancing autonomous robot

A robot that keeps itself upright while it also tracks targets, avoids obstacles and accepts manual control. I wrote a priority-based state machine on an STM32 Nucleo to coordinate those four jobs across I2C, UART and SPI, plus a PID loop above 100 Hz that turns BNO055 IMU readings into motor commands.

I designed the power side too: a 12V LiPo stepped down to clean 3.3V and 5V rails, and an emergency stop interrupt triggered by a VL53L0X distance sensor. The chassis cracked under load and we rebuilt it twice, and a few bugs we blamed on firmware turned out to be loose wiring.

Distributed file storage system

A fault tolerant storage system that splits files into checksummed chunks and replicates each chunk across separate Docker storage nodes, with PostgreSQL holding the metadata. When a node dies it is detected in about 15 seconds, files stay downloadable from the surviving copies, and full replication is back in under a minute. A background scrubber finds and repairs silent disk corruption.

I wrote the engineering spec, approved the architecture and 23 design decisions, and directed AI coding agents (Claude Code) through a six phase build, checking each phase against acceptance criteria before moving on. 65 automated tests cover live node crashes, disk corruption, database outages and API crashes mid upload, with zero data loss. It streamed 512 MiB files at up to 280 MiB/s using only 25 MiB of server memory.

In-memory database query engine

A command driven database (CREATE, INSERT, PRINT, DELETE, GENERATE, JOIN) with typed columns and pluggable indexes. Each column can carry a hash index and a binary search tree, and queries pick whichever one fits the filter, falling back to a linear scan when neither does.

JOIN uses a hash join that reuses an existing index or builds a temporary one, which brings the cost from O(n·m) down to roughly O(n+m).

Route planning for food delivery

Prim’s algorithm for minimum spanning trees over 2D coordinates, including a variant that forbids edges between safe and wild delivery zones. On top of it sit a greedy farthest insertion heuristic for the traveling salesman problem and an exact branch and bound solver whose MST based lower bound prunes the search far below brute force. I also compared Prim’s and Kruskal’s on different graph shapes.
